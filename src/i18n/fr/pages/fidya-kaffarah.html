Pour celui qui est incapable de jeûner de façon permanente, comme la personne âgée ou le malade dont on n’espère pas la guérison : nourrir un pauvre pour chaque jour.

Nombre de jours

Pour celui qui a rompu son serment : nourrir dix pauvres, les vêtir ou affranchir un esclave ; s’il n’en trouve pas les moyens, jeûner trois jours.

Nombre de kaffaras (serments différents)
Si le serment a été répété sur une même chose avant l’expiation, une seule kaffara est due selon la majorité des savants.

Dans l’ordre : affranchir un esclave ; s’il n’en trouve pas, jeûner deux mois consécutifs ; s’il n’en est pas capable, nourrir soixante pauvres.
